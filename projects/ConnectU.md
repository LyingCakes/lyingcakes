ConnectU was a mini social media application I made throughout the my ECE 367L Data Structures and Algorithms lab. The primary objective of the course to learn how to create and parse through efficient data structures that can be monumental in size, ie. a social media application. This application was programmed pretty much entirely in C++ with a csv to hold all of the 'users' information. This application is able to create new users, set friends, find friend recommendations, make posts, and receive posts made by friends.

Source Code: https://github.com/LyingCakes/ConnectU
