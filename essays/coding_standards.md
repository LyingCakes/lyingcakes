# The Good, Bad, and the Very Ugly
 
Coding is liberating, and constraining. A programmer must be able to write specific phrases in order to be understood by the machine hosting the software. So long as the compiler does not throw any errors, no matter how ugly or obfuscated the code may be, it will run. But, come back the next day and marvel at the intracacies of your utter nonsense, and try and piece together what the code actually does. Bonus points is if you are looking at the code from another programmer. On one hand there is the argument, "if it runs, it runs" but it is too simple of an opinion. Inenglish,wecanstillconveywhatwearetryingtosayevenwithoutspaces, but anybody who read what you wrote would have to take the extra moment to understand what you wrote, Germans exempted, and those extra moments add up. Coding standards are necessary rules to prevent unnecessary analysis, a skill that seperates the good from the bad.
 
# Unnecessary Space in Newline
 
To further our skills in code development ICS 314 has begun the transition away from using typescript playground to instead use big-boy and girl tools: VS Code and GitHub. When installing VS Code we were instructed to install a few more extensions and packages as well, namely ESLint. The rules for ESLint and what it throws errors for, are provided by ICS 314. Ideally this would make everybody's code conform to the same rules and be laid out in a similar format. Though, sometimes the rules can be very annoying. While exist good rules like enforcing spaces after commas, rules like only being able to use single quotes for strings can be mildly frustrating. So long as the compiler likes the code, Lint is only cosmetic, but obviously it is a technical requirement to have no ESLint errors for ICS 314. Still, I have noticed my programming naturally conform to the rules being enforced, and arguably it is making my code significatly more standardized and readable.
 
# A Necessary Evil
 
Lint can be frustrating. Coding standards can be frustating. Remembering to indent paragraphs can be frustrating. But standards in how we, humans, operate are what make the world go round. And though it may seem that conformity to these standards makes us lose a part of us that is special, the fact of the matter is, nobody cares about your specialty when they have to read your code at 2 in the morning. Lint is annoying. Being told how to write is annoying. And sometimes Lint may feel nitpicky. But nitpicks are what can prevent catastrophies from forming in the first place. And the only way to truly solve a problem in full, is to prevent it from ever happening.
