# Matryoshka

When first learning HTML it became quick that it would not be like a programming language that I am used to. While learning Typescript, the core syntax and terminology that was used was very reminiscent and comparable to other programming languages that I know, that being C and Python. Adapting to Typescript was easy, but when learning HTML it quickly became an oddity. In my eyes, HTML is language based entirely on nested commands, all working together to contribute an aspect to modify the text to be displayed a certain way. With so many methods and features to be able to change, HTML became not necessarily overwhelming, but difficult to understand what exactly each command had impact on the text.

# HTML++

Very quickly we were introduced to CSS and the styling options it provides and honestly, these new features had a syntax distinct from HTML and similar to C that the new features were easy to adapt to. CSS offers a simple way to modify aspects like margin and color in a way that makes sense to me, by having a list of parameters and new values to override their defaults. Even with IDs or types, modifying specific sections of the text how I see fit was a nice addition.

# C has classes like C++, right?

Bootstrap 5 on the other hand, was not like CSS. Like I said earlier, CSS presented itself in a different way to the syntax of HTML that I found confusing. Bootstrap is simply more features and commands for HTML. It became even more difficult to parse what exactly was contributing to the text in its modification. An example we had was to recreate a website of our choice with the caveat being that the original website cannot use Bootstrap, but our recreation must. Going through the source code of websites I could not even tell if it was made with Bootstrap because the commands used felt synonymous and could not be discerned by me. This is not Bootstraps fault per se, but I can see very quickly a future where I struggle to know what tools I have at my disposal given a programming task that either provides, or lacks Bootstrap.
